# Ceeker 0.61 desktop improvements

- Global Quick Search: Ctrl+Shift+Space while Ceeker is running. Change its shortcut under Settings → Desktop & shortcuts. Search remains offline, using the existing parser, tags and indexed contents. Up to 100 results are shown. Enter opens, Ctrl+Enter reveals in Ceeker, Alt+Enter reveals in Explorer; the context menu also previews and copies paths.
- Windows tray panel: click the Ceeker icon to browse the ten newest indexed downloads, open/reveal them or drag several together. Ordering is first observed by Ceeker, not browser download time. Only connected, indexed folders are included. Closing Ceeker exits the tray and unregisters its shortcut.
- Playful/Minimal styles: the header toggle or Ctrl+Shift+T switches dimensional artwork to outline category symbols and neutral panels. Light/dark appearance remains independent; orange branding is retained.
- Saved live searches: use Save search while a query is active. Saved searches retain query, folder/category/source and content/scope options. Relative dates are reevaluated on opening. Right-click to rename or remove. Up to 50 searches persist between runs.
- Automatic cleanup rules: explicitly enable under Settings → Folders & indexing. Choose one connected folder, preview eligibility and save. Installer recycling and screenshot filing are both off by default. Whole-drive rules are rejected. Installer age defaults to 90 days; age does not establish whether software is installed or needed. Screenshots use existing filename/type detection and move into Ceeker Screenshots/YYYY-MM by modified month. At most ten actions run after one minute, then every 30 minutes while idle and running. No overwrites; files are revalidated before changes. Local history records planned/completed/skipped actions. Cancel stops remaining actions; completed moves remain. Recycle Bin restoration is subject to normal Windows retention.
- Windows automation: bundled Ceeker.Actions provides read-only JSON search and latest-download actions plus desktop search launch commands. See WINDOWS-ACTIONS.md. This is a Windows CLI/PowerShell equivalent, not an Apple Siri integration.
- Preview navigation: a single selected file can navigate neighboring displayed results; multiple selection uses the selected subset. Left/Right step, Up/Down follow grid rows; Alt+arrows remain available when preview controls consume arrows.
- Multi-file drag: the main library and quick/tray list share existing validated copy-drag support. Recipient applications determine accepted drops.
- Responsive layout: narrower windows place search on another header row, reduce sidebar width, then expose a navigation menu at the smallest breakpoint. Selection and duplicate actions wrap. Ctrl+plus/minus adjusts thumbnail size.

Signed online updates and checkout remain inactive. Automatic rules do not run when Ceeker is closed. Preview release; see VALIDATION-0.61.md for tested coverage and remaining manual checks.
